#    语言名在语言选择器里永远写自己的文字。
# 2) 写进持久化数据、或要跟已有数据比对的值。换界面语言不该改动数据：
#    默认会话标题、默认文件夹名、附件种类前缀（都进 `session.title` / `session.folder`），
#    以及 `model_info` 里认旧版本标签用的「推理」。
# 3) 写给模型看的提示词。它们是请求体的一部分，跟着界面语言变会让同一个会话
#    在不同语言下产生不同请求体（prompt 缓存失效），而且里面的限制本身就是
#    中文语境的（「不超过16个字」翻成 "no more than 16 characters" 就不对了）。
#
# 新增一条之前先问自己：这是界面文案吗？是就翻译，别往这里加。
